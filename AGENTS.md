# Project guidance

## UI copy discipline

- Keep interface copy concise. Avoid redundant eyebrows, subtitles, helper text, badges, footnotes, and descriptions when layout, grouping, labels, or controls already explain the content.
- Prefer one clear page title and only supporting copy that establishes context or guides a decision.
- Use hierarchy, spacing, grouping, and interaction cues to explain relationships.
- Preserve text that communicates a required action, material status or risk, provenance, accessibility, or a meaningful limitation.
- Do not repeat the same action or explanation in multiple places on one screen unless the layout makes it necessary.
